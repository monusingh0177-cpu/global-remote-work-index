# Global Remote Work Index — datasets

Monthly hiring-index datasets from [StrideRecruit](https://striderecruit.com/en-US/career-statistics) (the StrideRecruit Hiring Index). Every figure is computed from the live job database on the date in `asOf` — nothing is estimated or invented.

## Files

One snapshot per month, plus `latest.*` copies of the newest month:

| File | Contents |
| --- | --- |
| `monthly/<YYYY-MM>.json` | Full snapshot: totals, remote share, top countries, categories, skills, sources, guides, locales, `asOf`, `canonicalUrl` |
| `monthly/<YYYY-MM>-countries.csv` | `country_code,country_name,live_roles,new_last_30_days` — fastest-growing countries (absolute new roles, only countries with at least 5 active roles are ranked) |
| `monthly/<YYYY-MM>-categories.csv` | `category,live_roles` — the 12 job-category slugs, most listings first |
| `monthly/<YYYY-MM>-skills.csv` | `skill,count` — most requested skills from live job titles |
| `latest.json`, `latest-countries.csv`, `latest-categories.csv`, `latest-skills.csv` | Copies of the newest month's files |

## How the numbers are made

- **Live roles** = visible listings (active, not expired, not demo) — the same count the StrideRecruit homepage publishes.
- **Remote share** = live roles whose source marks them remote, as a whole percent of live roles.
- **Countries** are ranked by new roles added in the last 30 days. A growth rate from a tiny base is never computed.
- **Skills** come from the site's curated title vocabulary, with a per-skill minimum bar.
- **Expired listings are excluded** from every count, so a role that is no longer live never appears in the data. Every listing links to the original source listing, where you apply.
- **As-of dating:** every file carries its `asOf` timestamp. Do not quote a figure without its date — hiring churn is fast.

## How this repo is updated

The datasets are generated by `scripts/export-hiring-index-data.ts` in the StrideRecruit codebase (`monusingh0177-cpu/global-career-jobs-platform`), which loads the same live report the career-statistics hub page reads, builds these files, and — when a repo-scoped token is configured on the server — commits and pushes them here. Without the token nothing is pushed. No data is ever written by hand.

## Reuse

Figures are published as-is with their as-of date. If you cite them, link to the live index: https://striderecruit.com/en-US/career-statistics

## Awesome-list submissions (human-gated only)

This repo is never submitted to any awesome-list or directory by a script or bot — automated bulk promotion is against GitHub's rules and list maintainers close self-promotion PRs as spam. If a human wants to propose this repo to a list, the checklist is:

1. Pick ONE list whose contributing rules explicitly allow data repos / hiring datasets.
2. Write the PR by hand, disclose the affiliation (StrideRecruit's own data repo), and link the live index — no marketing copy, no bulk submissions to several lists at once.
3. If it is closed, leave it closed; do not re-submit.
